## 📌 Objetivo

Este projeto foi desenvolvido com HTML5 com o objetivo de criar uma página web contendo meus sites favoritos.

A atividade trabalha conceitos básicos de desenvolvimento web, como:

- 🏗️ Estrutura HTML
- 🖼️ Inserção de imagens
- 🔗 Criação de links

---

## 📖 Sobre o Projeto

A página apresenta:

✅ Nome dos sites favoritos  
✅ Imagens representando cada site  
✅ Links clicáveis  
✅ Separação visual utilizando `<hr>`  
✅ Estrutura organizada com HTML5
